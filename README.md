VoltRelay Energy — EV Battery Swapping Analytics & Strategic Roadmap

An end-to-end Power BI Business Intelligence application built for VoltRelay Energy's EV battery-swapping network across 6 Indian cities (Bengaluru, Delhi NCR, Hyderabad, Jaipur, Mumbai, and Pune).
This repository contains the interactive Power BI report (.pbix), data schema definitions, DAX measure library, diagnostic Root Cause Analysis (RCA) models, and an executive prioritization roadmap (P0–P3) designed to mitigate rider churn, operational failures, and margin erosion.

VoltRelay operates a two-wheeler (2W) and three-wheeler (3W) battery-swapping platform. 
This project evaluates network scale, identifies service failure drivers, isolates customer retention bottlenecks, and presents an evidence-based roadmap to optimize network throughput and unit economics.

Core Business Metrics
Monthly Peak Volume: ~308,000 completed swaps 
Monthly Gross Revenue: ~₹20.0M INR 
Network Swap Completion Rate: 94.04% 
Overall Service Failure Rate: 3.76% 
Overall Abandonment Rate: 1.77%
